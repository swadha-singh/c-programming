# c-programming

A collection of beginner-friendly C programs created
while learning the fundamentals of C programming.

This repository documents my coding practice as a
BCA student and helps me build strong programming
and problem-solving skills.

## Programs Included

- Temperature Conversion
  - Celsius to Fahrenheit conversion
- Multiplication Table
  - Prints the multiplication table of a number
- Factorial of a Number
  - Calculates the factorial of a given number
- Area and Circumference of a Circle
  - Calculates the area and circumference using
    the radius
- Average and Sum of array
  - Calculates sum and average of an array entered
    by the user 

## Concepts Practised

- Variables and Data Types
- User Input and Output
- Arithmetic Operators
- Conditional Statements
- Loops
- Basic Mathematical Calculations

## Language Used

- C

## How to Run

1. Download or clone this repository.
2. Open any program in a C compiler.
3. Compile and run the program.
4. Enter the required input to see the output.
